# 요구사항 — 알림 전체보기 / 폰 원격 조작 / 설정 화면 분리

작성일: 2026-08-20. 이 문서는 Claude Approver v1.10 이후 추가되는 4개 기능의
요구사항을 정의한다. 구현 상세는 `design.md`, 작업 순서는 `tasks.md` 참고.

## 배경

기존 앱은 PC의 승인 요청을 폰 알림으로 중계하고(v1.0~), 자동 허용 모드(v1.6~)와
"폰 입력 모드"로 다음 지시를 보낼 수 있는 기능(v1.9~)까지 갖췄다. 하지만:

- 히스토리 목록/알림 본문이 길면 잘려서 전체 내용을 앱 안에서 볼 방법이 없다.
- "폰 입력 모드"는 Claude Code의 Stop 훅이 한 턴 끝에 최대 9분만 기다리는
  **일회성 프로세스**에 의존한다. 그 창밖에 보낸 지시, 또는 애초에 아무 세션도
  돌고 있지 않을 때 보낸 지시는 받아줄 프로세스가 없어 그냥 버려진다.
- 사용량/페어링 코드가 메인 화면에 늘 보여서 화면이 복잡하다.

## 요구사항 A — 알림 전체 내용 인앱 열람

**사용자 스토리**: 사용자로서, 승인 요청이나 완료 알림의 본문이 길어도 앱
안에서 잘리지 않은 전체 내용을 보고 싶다.

- WHEN 사용자가 "최근 요청" 목록의 항목을 탭하면, THEN 앱은 제목/전체 본문
  (스크롤 가능)/도구 이름/작업 폴더/시각을 잘림 없이 보여주는 화면(다이얼로그)을
  띄운다.
- WHEN PC 훅이 보낸 원본 텍스트가 ntfy 메시지 크기 한도 때문에 실제로 잘렸으면,
  THEN 그 사실을("내용이 길어 일부만 전달됨") 본문 끝에 명시한다 — 잘리지
  않았는데 잘렸다고 하거나, 잘렸는데 안 알리는 경우는 없어야 한다.
- WHEN 사용자가 상태 카드에서 "전체 보기"를 탭하면, THEN 가장 최근 "작업 완료"
  알림의 전체 본문을 같은 방식으로 볼 수 있다.
- WHEN PC 훅이 알림 본문을 만들 때, THEN 기존보다 넉넉한 길이(최소 1500자)까지는
  자르지 않는다.

## 요구사항 B — 폰에서 언제든 지시 + PC 깨우기

**사용자 스토리**: 사용자로서, PC 앞에 없을 때도 폰으로 Claude Code에 다음에
할 일을 지시하고 싶다. PC가 지금 아무 것도 안 하고 있어도 지시를 보내면 그걸
받아서 시작해줬으면 한다.

- WHEN "폰 입력 모드"가 켜져 있고 PC가 완전히 유휴 상태(작업 중도 아니고, 이미
  폰 입력을 기다리는 중도 아님)일 때 폰에서 지시를 보내면, THEN PC는 그 지시로
  새 Claude Code 세션을 시작한다(기존 승인/자동허용/완료알림 흐름 그대로 적용).
- WHEN PC가 이미 폰 입력을 기다리는 중(기존 Stop 훅 대기 창)일 때 지시를 보내면,
  THEN 기존 방식대로 그 대기 중인 세션이 이어받는다(중복 실행 없음).
- WHEN PC가 한창 작업 중일 때 지시를 보내면, THEN 시스템은 조용히 무시하지
  않고 "지금 작업 중이라 못 받았다"는 알림을 보낸다(대기열 적재는 이번 범위
  밖).
- WHEN "폰 입력 모드"가 꺼져 있을 때 지시를 보내면, THEN "모드가 꺼져 있어
  전달되지 않았다"는 알림을 보낸다(원인을 알 수 없는 채로 무반응이면 안 됨).
- WHEN PC 쪽 상시 대기 프로그램(데몬)이 켜져 있으면, THEN 앱은 이를 감지해
  "지금 보내면 처리된다"는 안내를 보여주고, 데몬이 꺼져 있으면 그 사실과 켜는
  방법을 안내한다.
- 데몬은 사용자가 수동으로 켠다(자동 시작 설정은 이번 범위 밖).

## 요구사항 C — 설정 화면 분리

**사용자 스토리**: 사용자로서, 자주 안 만지는 페어링 코드와 사용량 정보는
메인 화면에서 빼고 필요할 때만 열어보고 싶다.

- WHEN 사용자가 메인 화면의 설정 아이콘을 탭하면, THEN 페어링 코드 입력/연결
  화면과 사용량("오늘"/"현재 블록"/"평소 대비" 게이지)을 모아둔 설정 화면이
  열린다.
- WHEN 페어링이 안 된 상태로 앱을 열면, THEN 메인 화면에 설정 화면으로
  안내하는 배너가 보인다.
- 자동 허용 모드/폰 입력 모드 스위치, 다음 지시 보내기, 최근 요청 목록은
  메인 화면에 그대로 남는다(사용자가 자주 조작하는 항목).

## 비범위 (이번 라운드에서 하지 않는 것)

- PC 작업 중일 때 폰에서 보낸 지시를 큐에 담아두었다가 자동으로 이어 실행하는 것.
- 데몬 자동 시작(윈도우 시작프로그램/systemd 등록).
- 여러 프로젝트 폴더 중 어디서 실행할지 폰에서 직접 고르는 UI(기본은 마지막
  활동 폴더).
